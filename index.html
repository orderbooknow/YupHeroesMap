Связь
Связи (0)
Тип связи (цепочка ⛓ / кольцо ⭕ / звезда ✳) можно менять и у готовой: выберите её в списке и переключите тип. Связь на любое число точек: «🔗 Связь» → нажимайте метки по порядку → «Готово». Чтобы изменить связь, выберите её в списке и нажимайте метки: новая добавится, повторное нажатие уберёт её. Значок, цвет и размер задаются перед постановкой метки; чтобы поменять у готовой — «✎ Изменить». «👁» рядом со связью скрывает её только у вас. Правки видят все сразу; для редактирования нужен код редактора.
